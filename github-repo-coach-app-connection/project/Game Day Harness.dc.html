3

Fixing mistakes mid-game

Three levels of repair, all for the bottom of Game Day, below the fold. What goes wrong on a sideline, in rough order of frequency: the clock left stopped through live play; the clock left running through a break; a goal added to the wrong side or double-tapped; the scheduled sub never actually made, so the credit is wrong; the wrong chip tapped in a swap; Period + tapped twice; Reset tapped by accident.

Every one of those is already an append-only row in game_events, so a repair never edits history — it appends a correction. That's what makes all three of these safe to build.
